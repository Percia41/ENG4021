# Python — fundamentos

A revisão aborda tipos básicos (`int`, `float`, `str`, `bool`, `None`), variáveis, comentários, funções/imports, listas, dicionários, strings e conversões, comparações e operadores lógicos, condicionais, laços `for`/`while` e funções com parâmetros/`return`.

Listas usam índices a partir de zero; fatias selecionam intervalos; `append()` adiciona e `sort()` ordena. Dicionários associam chaves a valores. Converter tipos, por exemplo `str(numero)`, permite combinar números e texto. Esses fundamentos são usados pela lógica Python das views Django. Exemplos dos slides são didáticos e podem conter erros.

# HTML e CSS

HTML define estrutura e conteúdo: títulos, parágrafos, listas, links, imagens e formulários. Atributos como `href`, `src`, `id` e `class` configuram elementos. `div` agrupa; `span` marca trechos; elementos podem ser aninhados.

CSS define apresentação. Seletores por tag, ID (`#id`), classe (`.classe`) e descendente (ex.: `#pai p`) aplicam cor, fonte, largura, altura, fundo, borda, margem, preenchimento e posição. ID identifica um elemento; classes podem ser compartilhadas. No Django, CSS fica em `static` e é carregado pelo template.

O inspetor do navegador permite testar estilos durante depuração; alterações no inspetor não atualizam automaticamente o arquivo do projeto.
